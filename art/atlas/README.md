# Atlas production artwork contract, version 1

Original map art and representative unit animation sources are now authored as candidates. Missing coverage rows still identify unfinished production work; generated candidates are separate from release acceptance. AtlasTerrain and AtlasUnits are opt-in; no settings or defaults change. Animation is transient presentation only.

`scripts/atlas/assets.sh coverage` regenerates the union of both bundled rulesets and current map layer keys, retaining review state and evidence by exact row identity. It also creates missing per-unit `authoring.json` records. `validate` checks authoring bounds, exact path casing, source hashes, masks, mirrors, budgets and coverage freshness. `pack` emits deterministic animation PNG pages, runtime `manifest.json` and a compact hash report into `android/assets/atlas-animation/`. Neither command launches the app or scans mods. `--require-complete` additionally requires accepted original art with source and art-review evidence for every required row, provenance and all 127 units and their applicable clips. Fallback files never count as acceptance.

The earlier inventory is preserved as `baseline-inventory.json`, with its own original source commit and explicit incomplete status. The regenerated inventory records source hashes and added/removed unit names. Complete generic city designs are required for every era; nation/style variants are inventoried as optional overrides of those designs. Improvement commands such as Remove Forest are inventoried but do not require persistent map images. Neighbor transitions cover the terrain-name and Land/Water filters the renderer actually recognizes, with all six exact direction suffixes.

Authoring `manifest.json` has `schemaVersion`, `packing`, `budgets`, `units` and `clips`. Only authored, provenance-backed production entries belong in `units`/`clips`. Missing required work lives in coverage and per-unit authoring metadata. Use original illustrated raster images, not procedural placeholders. Unique units retain their own exact unit name and asset identity. All case-sensitive unit names are untranslated ruleset keys.

Parallel art builders can keep additive metadata in `art/atlas/units/<batch>-manifest.json`, `<batch>-provenance.json` and `<batch>-coverage-candidates.json`. Run `python3 scripts/atlas/assemble-unit-batches.py art/atlas/units/<batch>-manifest.json` after integrating the batch's source PNGs. Assembly replaces only that batch's named unit entries, preserves map and other unit records, and cannot promote candidate art to accepted. Then run `scripts/atlas/assets.sh pack` to rebuild shared runtime pages from the assembled source. Static AtlasUnits packing remains separate; never add animation pages to `Atlases.json`.

An authored unit has `unitName`, `assetId` (the inventory slug), `canvasWidth`, `canvasHeight`, `anchorX`, `anchorY`, `staticLayers`, `maskKeys`, nullable `shadowKey`, `clippingMargin`, nullable `uniqueUnitIdentity` and `applicableStates`. Canvas is 128×128 or 192×192; anchors use top-left coordinates inside that untrimmed canvas. Static layer/mask/shadow keys resolve to PNGs under `android/Images.AtlasUnits/TileSets/AtlasUnits/Units/`. Distinct unique units need distinct reviewed art.

An authored clip has `unitName`, `state`, `facing`, `staticFallbackKey`, `looping`, nullable `mirroredFacing`, `maskIds`, `hasShadow` and ordered `frames`. States are IDLE, MOVE, ATTACK, HIT, DEFEAT, WORK. Facings are E, NE, NW, W, SW, SE. Every frame has positive `durationMs`, `color`, ordered `masks` and nullable `shadow`. A source rectangle is `{path, x, y, width, height}`; frame masks are `{id, source}`. Source PNG sheets live under `art/atlas/units/<assetId>/frames/`. All corresponding sheets have matching dimensions and source rectangles, in the declared mask order. Author frames at the full canvas size. Minimum counts are IDLE 4, MOVE 8, ATTACK 8, HIT 4, DEFEAT 8, WORK 8. Art review must establish that the animation is visibly appropriate; the packer only rejects wholly transparent or repeated static color frames.

Mirroring is explicit and limited to horizontal pairs E/W, NE/NW, SW/SE. A mirrored authoring clip has an empty frame list and points to a non-mirrored source of the same exact unit/state, matching mask, shadow, looping and fallback declarations. Its runtime frames share the source regions. Playback must flip horizontally around the original canvas anchor, taking trim offsets into account. No unit or state is substituted implicitly.

Packing trims the union of color, masks and shadow plus `clippingMargin`, retaining original canvas size and anchor. Ordered shelf packing never rotates regions. All layers use identical placements, page dimensions, region names and frame order, with edge-duplicated padding. Animation page size is at most 1024 and power of two. Static Atlas sources retain a scoped 2048 maximum; unrelated texture settings are unchanged. Animation PNGs are never included in `Atlases.json`.

Runtime `AtlasArtManifest` parses mutable DTOs into immutable defensive collection copies. `findUnit(name)` and `findClip(ClipKey)` return null for absent exact identities, including ordinary mod units. `ClipKey` holds `(unitName, state, facing)`. `UnitArtSpec` publishes the authored unit metadata above. `ClipSpec` publishes `key`, ordered `frames`, canvas `anchorX/Y`, `staticFallbackKey`, sorted unique `pageNames`, nullable `mirroredFacing`, `looping`, `decodedBytes`, `decodedStagingBytes` and `gpuBytes`. `FrameSpec` has color `FrameRegion`, ordered `FrameMask` values, optional shadow region, duration, original canvas dimensions, trim offsets and trimmed-relative anchors (`canvasAnchor - trimOffset`). Region coordinates use a top-left origin. A `FrameRegion` contains `pageName`, `regionName`, `x`, `y`, `width`, `height`. A `FrameMask` contains `id` and `region`.

`PageSpec` contains `name`, relative `fileName` (`name.png`), `layerId` (`color`, `mask:<id>` or `shadow`), width/height, `mipmaps`, `decodedBytes` and `gpuBytes`. All pages are RGBA8888. `decodedBytes` is `width*height*4`. GPU bytes include every mip level, down to 1×1 when enabled. Clip `decodedBytes` is the sum of its unique page bytes; `decodedStagingBytes` is the largest single-page decode, describing the minimum peak possible with sequential decoding/upload. The runtime cache must account for the actual sum of all concurrently queued decoded pages/layers, capped at 8 MiB, and count resident/uploading GPU allocations against 128 MiB desktop or 32 MiB elsewhere. A clip's total GPU bytes must fit the smaller platform cache. The `ClipHandle` interface is an idempotently closed pinned metadata view; the runtime cache owns texture disposal. This foundation does not implement the cache or loader.

Provenance entries have exactly `{assetId, creator, source, promptPath, rights, sourceHash, outputHashes}`. Rights are `original` or `original-generated`. `promptPath` is a tracked authoring prompt/creation record. `source` is a relative path to the original creation input or generation record, and `sourceHash` verifies its SHA-256; `outputHashes` maps every shipped source path to its SHA-256. Source references and third-party inspiration do not become shipped art. Large rejected candidates, contact sheets and raw timing artifacts stay on Lexar. Accepted source PNGs, prompts, provenance and compact packing metadata are tracked.

AtlasTerrain border strips are exact engine geometry rather than illustration: a thin line on the shared hex edge and a soft inner tint, with mitred ends. `art/atlas/terrain/gen_borders.py` draws all eight, patches their packed regions into `android/assets/AtlasTerrain.png` in place, and refreshes their provenance, coverage evidence and packaging hashes. `normalize_sources.py` refuses border cells.

Coverage review states are `missing`, `candidate`, `accepted`. Evidence is an ordered list of `{kind, path, sha256, reviewer, note}`; accepted rows need both `source` and `art-review` entries pointing to tracked, exact-case, hash-matching files. Acceptance is explicit and separate from existence, packing or compilation.

Implementation-pass validation is deferred: no tests, render audit, review, performance/native acceptance or complete-coverage claim accompanies this foundation.
