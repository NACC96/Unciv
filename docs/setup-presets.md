# Setup presets and starting bonuses

Use **Presets** at the bottom of the new-game screen. Enter a name and click **Save preset** to save the full setup: selected nations and control types, agent provider/model/reasoning/name/personality, starting bonuses, map parameters and seed, and game options. Cached agent settings for slots currently set to Human or AI are retained too. Select a saved preset and click **Load** to restore it; loading does not start the match. Resizing setup also preserves agent assignments and profiles.

Saving an existing name updates it, preserving the previous file as a backup. Presets are JSON files under `SetupPresets` in the Unciv data directory. This installed macOS build uses `/Volumes/Lexar/Unciv/userdata`; unconfigured native builds use `~/Library/Application Support/Unciv`. Unreadable files are left unchanged and reported. A custom map is referenced by its absolute path; a missing map produces an error instead of silently generating a replacement. Presets store configuration, not account authentication.

Custom-map discovery skips hidden macOS metadata files and directories. An unreadable map is logged and skipped individually so other maps remain selectable. Extensionless and compressed maps are supported. The Legendary Earth presets reference the verified map under `userdata/maps` on Lexar; their original preset files were backed up before changing only the map path.

Open a nation's **Edit** button to set extra starting gold and culture, add unit types/counts, and add strategic-resource deposit types/counts. This works for agent, human and built-in AI nations. Agent fields and starting bonuses save together; Cancel discards edits. The form scrolls while Save/Cancel remain fixed below it. A zero count removes a unit/deposit selection. Counts allow up to 50 per unit type and 10 per deposit type. Units come from the selected ruleset, including that nation's unique units.

Bonuses are additional to the ordinary era/difficulty starting grants. Gold, culture and ordinary units apply once during game creation. Aircraft and missiles wait until the nation founds a city, then arrive in owned cities using normal air-unit capacity. Excess units remain pending and retry at the start of each turn and when another city is founded. Pending grants survive save/reload and cloned game snapshots; delivery consumes each grant exactly once. Random nation slots carry their bonuses to the resolved civilization. Loading a game does not repeat delivered bonuses.

The floating civilization **Overview** shows **Pending starting units** under Units for spectators and the nation's own player. Agents also receive their own pending grants in `game.observe` under `empire.pendingStartingUnits`, separately from deployed units. Other nations' pending grants remain private in human games.

Deposits are actual new resource tiles within four tiles of the starting location. Natural locations are preferred; when those run out, setup uses other empty tiles in the resource's land/water domain where an extraction improvement can be built. Terrain stays unchanged unless removable features prevent extraction. Existing resources, improvements, natural wonders, impassable tiles and other nations' territory are preserved. Deposits avoid starting tiles and must be closer to the recipient's start than to any other start. Their quantities follow the ruleset's major-deposit amounts. They still require normal technology, ownership and improvements to supply resources. If there is physically too little usable space or room for ordinary land/naval units, game creation reports an error; bonuses are never silently dropped. Aircraft and missiles do not require an air base during map generation.

For an agent spectator preset, choose **Watch agents play (Spectator)** before configuring and saving the roster. After loading that preset, click **Start game!** directly: Watch agents play creates a new random roster.
