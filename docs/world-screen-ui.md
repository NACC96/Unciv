# World-screen UI, first pass

Selected October 10, 2026: modern controls with the existing pixel-art map. Scope is the world screen; setup, city, research, diplomacy and other screens retain their current styling.

- Charcoal surfaces, off-white text and a restrained teal interaction accent. Civilization portraits retain the game's ownership colors.
- A compact top bar with civilization identity, economy, turn/year and strategic resources. In agent spectator matches it follows the active civilization. Stat clicks inspect that same civilization; Overview opens the live all-civilization panel. These controls do not switch the map's viewing perspective or grant turn authority.
- Narrow windows stack identity and statistics instead of overlapping controls. Long identity labels truncate; full civilization names remain in the activity feed.
- Smaller Overview, Fog of War, Pause/Resume, Activity, next-turn and auxiliary controls. Map-layer toggles use neutral square controls and a selected tint.
- A floating activity feed with configured agent names, stable agent colors, civilization portraits and turn separators. Messages are brighter and provider reasoning is subdued. Consecutive tool calls collapse into the latest call and an expandable count; messages, errors and agent/turn changes end each group. Expand a group to see every call, then a call to inspect its real arguments/results and Copy details.
- Every message and thinking entry repeats the colored agent name; tool groups and errors identify their speaker too. The background captures just the panel's map region and applies a GPU blur with a translucent charcoal tint, rounded edges and a subtle rim. Text stays sharp. Resize recreates the small buffers, hiding the feed stops its drawing, and disposal releases its graphics resources. Unsupported shaders fall back to a translucent surface and log the failure once.
- Live advances gradually at 40 logical pixels per second, with no large jump after a stalled frame. Mouse-wheel steps are 24 pixels. Scrolling or expanding a tool suspends following, preserves the entry being read even as earlier paragraphs grow, and counts new entries. Live jumps to the latest entry and resumes following; Earlier loads older activity; Logs opens the saved journal directory.

HUD colors, spacing and button states live in `WorldScreenStyle.kt` and do not change the global skin. The original menu shortcuts, map pan/zoom, agent pause boundaries and gameplay authority checks are retained. The feed is an ordinary scene actor; only its rectangle captures input.

The Overview button (or existing Empire Overview shortcut) toggles a floating, draggable Civilizations panel, initially on the right. This is an extension of the established HUD, with the same glass material, type hierarchy and stable agent accents. The map and match controls remain active outside its rectangle. A sortable comparison sits above selected-nation details; narrow layouts retain score/science and move the remaining stats into details where permitted. [Civilization overview](civilization-overview.md) records its filters, interaction and privacy behavior.

The panel reads the GL-thread game publication, refreshes twice per second and on world updates, and preserves selection, search, sorting and available scroll positions across snapshots. It clamps its position and layout when resized and disposes its timer and glass resources with the world screen. Spectators see every nation, including defeated nations, and full statistics. Human viewers see themselves and met nations; existing ranking visibility settings apply to public comparisons. Private opponent economy, research queues, resource inventory, city production and unit lists remain hidden even when rankings are allowed. Opening the panel never changes the selected map civilization or gameplay authority.

Deferred: user resizing of individual panels, feed filters and map links, historical charts/replay, terrain art, city banners and the remaining application screens.
